# 滑块拼图

做一个 1280×720 的 3×3 滑块拼图小游戏，标题文案必须是 Slide Puzzle。禁止随机打乱，开局棋盘固定。

## 开局

- 按钮 Start 矩形 (440,620,400,70)。点 Start 或按 Enter 开始，开始后立即进入 playing，没有倒计时。
- 开始前棋盘已经画出，但点击棋盘、方向键和 Reset 都不生效。Start、Reset 与棋盘三块矩形互不重叠。

## 棋盘

- 棋盘 480×480，左上角 (400,120)，每格 160×160。
- 开局固定布局（0 表示空位）：

```
1 5 2
4 0 6
7 3 8
```

- 目标布局：

```
1 2 3
4 5 6
7 8 0
```

- 画面上棋盘格显示数字 1–8，空位不画方块。

## 规则

- 一次滑动：把与空位上下左右相邻的一块滑进空位，moves+1。
- 点击相邻的方块滑动它。方向键滑动方块的方向与键名一致：ArrowLeft 把空位右侧的方块向左滑，ArrowRight 把空位左侧的方块向右滑，ArrowUp 把空位下方的方块向上滑，ArrowDown 把空位上方的方块向下滑。该方向上没有方块（空位在边上）则什么也不发生，moves 不变。
- 点击不相邻的方块、空位或棋盘外，什么也不发生。
- 按钮 Reset 矩形 (60,620,240,70)，按 R 键同效，仅在 playing 时生效：棋盘回到开局布局，resets+1，moves 不清零，也不算一次滑动。
- 画面须持续显示 moves / 14 与 resets。
- 当棋盘等于目标布局，通关，画面 Puzzle clear。该判定先于步数判定。
- moves 达到 14 且棋盘不是目标布局，失败，画面 Puzzle fail。
- 同一帧内只处理一个输入：键盘优先于点击；多个按键按 Enter、R、ArrowLeft、ArrowRight、ArrowUp、ArrowDown 的顺序取第一个。
- 通关或失败后，方向键、点击、Reset（含 R 键）都不再生效，画面停在结束状态。

## 素材

工作区有只读 Kenney CC0 图库 `asset-library/`，可自选素材美化方块、背景和按钮，也可以不用。

## 验收会看的玩法

未开始的标题（Start 与已摆好的棋盘）、滑动若干步的循环（数字方块位置在变，moves 在涨）、按 Reset 回到开局布局（resets 变化）、在 14 步内没有还原（Puzzle fail，画面仍显示 14 / 14）、还原目标布局（Puzzle clear）。整张棋盘只有一行数字文字、看不出 3×3 方块的，不算把拼图画出来。

## 实现约束

- 画面逻辑尺寸 1280×720，恰好一个场景。
- 禁止随机。禁止用物理引擎决定对错。
- 不要实现评测探测接口。不要读取评测仓、量表或官方操作表。
- 提交物须含可重放 traces（放在 demo_outputs，每条标明 intro / loop / fail / clear 之一）。每条 trace 重放时长不超过 20 秒；loop 那条须包含至少一次 Reset，且 Reset 前后各停留至少 1 秒。
